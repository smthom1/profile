# Win98 Portfolio

An interactive, nostalgic web portfolio built with React and Vite. This project migrates a static Windows 98-style portfolio into a sophisticated, modern web application.

## Features

- **Component-Based Architecture**: A modular structure built with React.
- **Fluid Window Management**: Interactive, draggable, and resizable windows powered by `framer-motion`.
- **Minesweeper Port**: Includes a fully functional port of the classic Minesweeper game.
- **Dynamic Theme Switching**: Easily toggle between the classic, retro Windows 98 aesthetic and a modern, glassmorphic Windows 11 interface.

## Technologies Used

- [React](https://reactjs.org/) (v18)
- [Vite](https://vitejs.dev/) - Next Generation Frontend Tooling
- [Framer Motion](https://www.framer.com/motion/) - Animation library for React
- [Lucide React](https://lucide.dev/) - Beautiful & consistent icons

## Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

You need to have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository (if applicable) or navigate to the project directory:
   ```bash
   cd MAIN
   ```

2. Install the dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```
   This will start the Vite development server. Open your browser and navigate to the local URL provided in your terminal (usually `http://localhost:5173`).

### Building for Production

To build the app for production to the `dist` folder, run:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
